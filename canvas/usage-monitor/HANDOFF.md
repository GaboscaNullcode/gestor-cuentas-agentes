## User flows

### Add and sign in to an account (`add-account`)

Storyboard `Flow.add-account.dc.html` · snapshot `snapshots/Flow.add-account.png`

1. **Panel--empty** — First run: an empty state that explains the app and offers one action.
2. **AddAccount** ← `go:AddAccount` — Import a detected session in one click, or name a new one. The folder hides under Advanced.
3. **SignIn** ← `go:SignIn` — Three steps show progress; the code step only appears when the CLI asks for it.

### Remove an account (`remove-account`)

Storyboard `Flow.remove-account.dc.html` · snapshot `snapshots/Flow.remove-account.png`

1. **Panel** — Destructive actions live behind the more button, not on the card.
2. **Panel + AccountMenu** ← `open:AccountMenu` — Rename, copy the alias, open the folder or remove.
3. **Panel + RemoveAccount** ← `open:RemoveAccount` — A sheet states what will happen before anything is deleted.

### Fix a signed-out account (`reconnect`)

Storyboard `Flow.reconnect.dc.html` · snapshot `snapshots/Flow.reconnect.png`

1. **Panel** — The notice row pairs the problem with its fix.
2. **SignIn** ← `go:SignIn` — Reconnect reuses the sign-in steps for the same folder.

### Filter by provider (`filter`)

Storyboard `Flow.filter.dc.html` · snapshot `snapshots/Flow.filter.png`

1. **Panel** — All accounts, with a count per provider.
2. **Panel--claude** ← `do:show only Claude accounts` — Only Claude cards; Most headroom narrows to Claude. The choice is remembered.
